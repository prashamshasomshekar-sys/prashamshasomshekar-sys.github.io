## ✨ Features

- **Painted multi-layer scenery:** sky, clouds, Mt Fuji, ridges, town, forest, pagoda and blossoms, all drawn in code on an HTML canvas with parallax depth
- **Day-to-night scroll journey:** the scene changes as you scroll and ends with a full-screen "Thank you" over the night painting
- **Sakura petal cursor:** leaves a sparkle trail and shines with a burst of light and petals when you click
- **Petals that react to your mouse:** falling blossoms swirl away from the cursor
- **Hanging scrolls (kakejiku):** projects that unroll on click, plus "Currently learning" scrolls
- **Horizontal handscroll (emakimono):** the Skills section unrolls sideways between wooden rollers
- **Slash reveal:** each section appears with a glowing cut
- **Works on phones:** lighter effects and tap-to-shine on mobile; respects "reduce motion" settings

## 📁 Files

```
index.html      → the page content
style.css       → colours, fonts and layout
script.js       → the painted world, petals, cursor and animations
portfolio.html  → single-file version of the whole site
build.js        → regenerates index.html, style.css and script.js from portfolio.html
```

## 💻 Run it locally

Just open `index.html` in any browser, with no install needed.

After editing `portfolio.html`, rebuild the site files with:

```bash
node build.js
```
